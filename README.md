# ESNEMEN MECLİS TUTANAĞI

> Resmi sınıflandırma: Ciddi. Gayriresmi sınıflandırma: Ciddi değil. İkisi aynı damganın iki yüzü.

Bu depo, bir insanın esnemesini yasama faaliyetine çevirir. Katılımcı yoktur. Kürsü yoktur. Çay ocağı vardır ama çay henüz gelmemiştir. Yetersayı, esnemenin saniye cinsinden uzunluğudur. On saniyenin altı “taslak esneme” sayılır ve tutanak alt komisyona, yani yastığa iade edilir.

## Neden var

Çünkü birisi “durduk yere aklına bir şey takılırsa repo aç” dedi. Aklımıza esneme takıldı. Esneme evrenseldir, partiler üstüdür ve hiçbir bakanlığın bütçesinde kalemi yoktur. Biz kalemi açtık.

## Kurulum

```bash
python3 tutanak.py
```

Python 3 yeter. Bağımlılık yok. İnternet yok. Vicdan opsiyonel.

## Kullanım

```bash
python3 tutanak.py --sure 14 --konu "gündem" --vekil "Sıra No 404"
python3 tutanak.py --demo
```

Çıktı, resmi tutanak formatında bir metin ve `cikti/tutanak.txt` dosyasıdır. Dosya yoksa klasör kendi kendine açılır; bürokrasi buna “kendiliğinden teşekkül” der.

## Yasal uydurma

- Madde 1: Esneme bir oy değildir. Esneme bir oy gibi davranır.
- Madde 2: Ağzı kapatan kişi çekimser sayılır.
- Madde 3: İki kişi aynı anda esnerse koalisyon kurulmuş sayılır ve derhal dağılır.
- Madde 4: Bu yazılım hiçbir meclisi, partiyi veya sandalyeyi temsil etmez. Sandalye temsil edilmek istememiştir.

## Gizli ek

`protokol/ek-c.b64` dosyası tutanak dışı nottur. Açmak zorunda değilsiniz. Açarsanız da sadece yorgunluk hakkında konuşur. Siyaset konuşmaz. Siyaset esner.
